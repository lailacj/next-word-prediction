# Archived code

These files are preserved for reference and excluded from the installed package and test suite:

- `playground/`: the original experiments, model implementations, and standalone runners.
- `fix_csv.py`: the original one-off CSV deduplication script.

Their paths and instructions describe the old repository layout. Some files load models or modify files immediately when imported; `qwen_pseudocode.py` is an incomplete draft. Review and adapt any useful logic before reusing it.

Use [src/next_word_prediction/](../src/next_word_prediction/) for maintained code and [playground/](../playground/) for new experiments.
